# 假设格式模板

提出新的改进假设时，必须完整填写以下所有部分：

```
假设ID: HXXX
瓶颈: 简要描述具体瓶颈
文献支撑: 相关论文/方法

───────────────── 推理链 ─────────────────
步骤 | 内容                  | 置信度 | 推理方式 | 依据来源
S1   | ...                   | 高/中/低 | 文献/演绎 | ...
S2   | ...                   | ...    | ...     | ...
...
综合置信度 = 所有步骤最低（木桶效应）

───────────────── 验证标准 ─────────────────
Q1 如果核心指标提升 < 5%，是否仍保留？
答：是/否
理由：...

Q2 如果指标下降，最可能的原因是什么？
答：...
理由：...

Q3 本假设的最低可接受结果是什么？
答：...

───────────────── 改进方案 ─────────────────
改动文件: src/xxx.py
改动内容: 具体改什么
验证指标: pipeline 跑 N 个分子，对比改前改后的结合能 + trivial 比例
```
