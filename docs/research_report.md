- **H015**: 新增 5 条饱和含氮杂环规则（THIQ、吲哚啉、四氢喹啉等）

   - 氟代饱和双环体系

## 5. 迭代过程的科学洞察

### 洞察 1: 多样性是突破天花板的关键
- H011 (MMD 选择) 和 H022 (骨架库) 是两次最大的 BE 跃升
- 单纯优化结合能（贪心选择）导致过早收敛
- 多样性保持选择 + 多样化种子库 = 探索更优化学空间

### 洞察 2: 逆合成规则覆盖率直接决定合成可行性
- H015 的饱和 N-杂环规则首次实现 0/10 trivial
- H020 的杂环规则修复了 combine 策略的 trivial 回归
- 验证了 LARC (2025) 的核心观点：规则覆盖率是关键

### 洞察 3: 累积效应 > 单次改进
- 后期突破（H022, -10.359）依赖前期基础设施：
  - H011 的多样性选择保留了 THIQ 骨架
  - H015 的逆合成规则为 THIQ 提供了路线
  - H020 的规则覆盖防止了 trivial fallback
- 每轮迭代为后续突破铺路

### 洞察 4: 化学空间转向
- 前期: 联芳酰胺/联芳醚 → 最高 ~-9.9 kcal/mol
- 后期: THIQ/四氢萘/饱和双环 → 突破 -10.4 kcal/mol
- TYK2 JH2 口袋偏好形状互补的饱和双环体系

## 6. 最终结论

MolCraft Agent 在 14 轮自主迭代中完成了从文献解析 → 瓶颈诊断 → 代码演进 → 实验验证的完整科研闭环：

1. **结合能**: -8.1 → **-10.4 kcal/mol** (+28% 提升)
2. **合成可行性**: trivial route 从 30% → **0%**
3. **化学多样性**: 从简单联芳 → THIQ/桥环/螺环体系
4. **自主性**: 零人工干预，14 轮完整闭环迭代

### 限制
- 逆合成规则仍为启发式（非 AI 预测），覆盖度有限
- 对接评分（Vina）为近似值，与实验结合能有系统误差
- 生成分子需经过湿实验室合成和生物测试验证

### 未来方向
- 引入 AlphaFold 预测的蛋白结构提升对接精度
- 基于 LLM 的逆合成预测（如 LARC agent 框架）
- 多目标优化（结合能 + 选择性 + ADMET）
