## 二、论文新解读（聚焦未利用的方法论）

### 1. LARC (Baker et al., 2025) — Agent-as-a-Judge 逆合成

**之前已用**: 规则覆盖率原则 → 扩充 REACTION_RULES 到 35+ 条

**尚未用到的核心思想**:
> LARC 不仅强调规则覆盖率，更强调**路线质量评审是多目标优化的关键维度**。
> 一个低结合能的分子如果路线不可行，仍然不是好候选物。
> LARC 使用 LLM Agent 作为评审者，对每条逆合成路线打分。

**新映射到本项目**:
- `score_route_quality()` (H012 已实现) 可以计算每条路线的合理性分数
- 但目前 pipeline 选择 Top-N 分子时**只看结合能**，路线质量分数未被使用
- 改进方向：将路线质量作为分子选择的第二维度，形成 BE + Route Quality 双目标优化

### 2. Coscientist (Boiko et al., 2023) — 多模块自主实验

**之前已用**: 对接引导生成 (H002)、进化迭代框架

**尚未用到的核心思想**:
> Coscientist 的核心架构是 **Planner → Web Searcher → Code Execution → Feedback 闭环**。
> 每次实验后，结果反馈给 Planner 用于下一轮决策。
> 这种"执行-评估-改进"循环是 Agent 自主性的关键。

**新映射到本项目**:
- 当前 pipeline 已有进化迭代（H001），但缺少**显式的分子质量反馈环**
- 改进方向：在每代结束时，将路线质量和合成可行性的反馈纳入下一代种子选择

### 3. ChemReasoner (Sprueill et al., 2024) — LLM + DFT 假设验证

**核心思想**:
> LLM 提出催化剂假设 → DFT 计算验证 → 反馈修正假设。
> 关键是 **DFT 计算的客观反馈** 用于纠正 LLM 的推测。

**映射到本项目**:
- 我们的 docking（类比 DFT）已经提供客观反馈
- 但路线质量没有作为反馈信号
- 改进方向：路线质量评分 → 反馈到选择函数

### 4. JACS Deep Lead Optimization (2024) — Fragment Replacement

**核心思想**:
> Fragment Replacement 是四大核心子任务中我们唯一未实现的。
> 定义：替换分子的某个片段（由 BRICS 断键识别）为另一个功能相当的片段，
> 同时保留其余部分不变。

**现有基础**:
- BRICS 分解 (H018)
- 片段池构建 (H018)
- Scaffold Hopping (H010) — 类似但操作骨架层
- 缺少的是**片段级别的替换**（保留骨架，只换侧链/子结构）

## 四、本轮迭代方向

选择 **H019: 路线质量集成到分子选择**。

理由：
1. **低门槛高回报**: 只需修改选择函数（~30行），不需要新的化学操作
2. **已有基础**: `score_route_quality()` 已实现且测试过（H012）
3. **文献支撑强**: LARC 明确强调路线评审在多目标优化中的核心地位
4. **填补关键缺口**: 当前只优化 BE，忽略了"合成可行性"这一关键维度
5. **低风险**: 作为权重项叠加，不影响现有逻辑
