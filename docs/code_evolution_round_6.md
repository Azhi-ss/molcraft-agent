## H014: 逆合成化学计量验证

### 假设ID
H014

### 修改文件
`src/synthesis_v2.py` — `_run_retro_rule` 函数

### 修改内容摘要
在逆合成规则匹配成功后增加化学计量守恒验证：
1. 计算目标分子的重原子数
2. 计算规则生成的原料重原子数总和
3. 若比例超出 [0.7, 1.3] 范围，拒绝该规则匹配（返回 None）
4. 递归逻辑自动尝试下一条规则或回退到 BRICS

### 文献依据
- LARC (Baker et al., 2025): Agent-as-a-Judge 框架强调逆合成路线必须满足多维度验证，化学计量守恒是基本前提
- ChemCrow (Bran et al., 2024): 工具输出质量评估决定下游决策可靠性

### 技术细节
- 阈值选择: 0.7-1.3（30% 容差），基于测试验证
  - 取代喹啉(17) / 无取代原料(12) = 1.42 > 1.3 → 正确拒绝
  - 裸喹啉(10) / 原料(12) = 0.83 → 通过，但裸喹啉本身即简单起始原料
  - 酰胺(19) / 原料(19) = 1.0 → 正常通过
- 使用 `GetNumHeavyAtoms()` 排除氢原子干扰
- 解析异常时保留原有行为（不拒绝）
