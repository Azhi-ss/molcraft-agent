# 诊断报告 — Round 12

## 1. 文献解析关键发现

### LARC (Baker et al., 2025) — Agent-as-a-Judge 逆合成框架
- **核心观点**: 规则覆盖率是逆合成质量的关键决定因素。更多规则 → 更少 trivial route。
- **技术要点**: 逆合成路线必须通过化学计量守恒验证（mass balance check）。
- **映射**: → `synthesis_v2.py` 的 `REACTION_RULES` 列表

### ChemCrow (Bran et al., 2024) — 18 工具集成
- **核心观点**: 工具/规则库的丰富度直接决定 Agent 能力边界。
- **技术要点**: 每条规则对应一种真实化学反应。
- **映射**: → 当前 35+ 条规则，仍有明显缺口

### Deep Lead Optimization (JACS 2024) — BRICS 16 种可断裂键
- **核心观点**: BRICS 定义了 16 种化学合理的断键类型，RETROSYN 规则应覆盖其中关键类型。
- **技术要点**: 片段重组（Fragment Replacement）需要逆合成规则配套。
- **映射**: → H019 失败的根因 — 新 BRICS 重组骨架无逆合成规则覆盖

## 2. 瓶颈诊断

### 瓶颈 1: BRICS 重组产物的逆合成覆盖不足（优先）
- **根因**: `REACTION_RULES` 缺少对高频药物杂环（吲哚、苯并呋喃、四唑、异噁唑）的合成规则
- **影响**: combine 策略下 trivial ratio 回升（1/10），且限制了分子多样性
- **证据**: result.csv 中 `Cc1ccc2c(c1N)Cc1ccccc1C2`（二苯并氮杂䓬）落入 BRICS fallback

### 瓶颈 2: 二芳基胺键的逆合成遗漏
- **根因**: 现有 Buchwald 规则 `[c][NX3;H1]` 仅匹配 N 连接一个芳基，不匹配 N 连接两个芳基
- **影响**: 二芳基胺类分子（药物化学核心 motif）无合成路线

### 瓶颈 3: 结合能已近天花板
- **状态**: -9.0 ~ -9.9 kcal/mol，H011 MMD 选择后提升显著
- **策略**: 不再主攻结合能，转向路线质量和分子多样性
